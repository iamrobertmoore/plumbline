Repository audit

Does this repo do what it says?

Paste any public GitHub repository. Plumbline reads its README and manifest as a list of claims and tests every one: the links, the files it points at, the install command, the published version, the licence.

  4. Asking the package registry
  5. Checking the licence GitHub can see

Everything the README promises

Links to other sites, links to files in the repository, the install command, the version in the manifest, the licence it names.

Evidence

Every verdict is clickable

A failed claim comes with the address that failed, so you can open it and see the 404 yourself before believing a word of this.

Bounds

Untested is never passed

A link that could not be reached is reported as untested. The limits on a hosted run are printed with the result, every time.
