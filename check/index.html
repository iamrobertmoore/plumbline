Paste any public GitHub repository. Plumbline reads its README and manifest as a list of claims and tests each one: the links, the files it points at, the install command, the published version, the licence.

This page runs the free half of Plumbline: the checks that need no judgement, so no AI model is involved. It is the same code that measured the 100 most-starred installable repositories on GitHub. Every bound on a run is printed with the result. A link that could not be reached is reported as untested, never as working.
